# Coding-agent instructions

- Use Bun; do not add npm, pnpm, or yarn lockfiles.
- Run `bun test` before editing and record the failure.
- Make the smallest implementation change that satisfies the issue.
- Run `bun test` and `bun run typecheck` after editing.
- Commit the fix on a new branch and open a pull request against `main`.
- Never merge the pull request.
